Key Benefits
------------

✅ Zero Configuration: Just set SIM_AGENTS_ENABLED=true
✅ Automatic: Agents registered on session creation
✅ Consistent: Same agent setup for all autoplay sessions
✅ Testable: Comprehensive test suite validates behavior
✅ Manageable: Full API for monitoring and control
✅ Performant: In-memory storage, no DB queries per tick
✅ Documented: Complete guides and examples


Notes
-----

[1] Agent instances stored IN-MEMORY in AgentRegistry
    - Fast access (no DB queries during tick processing)
    - Persist for server lifetime
    - Automatically re-registered on server restart

[2] Agent behavior parameters and activity ARE persisted in PostgreSQL
    - simulation.participants table
    - simulation.orders table
    - simulation.trades table

[3] Registration only happens for NEWLY CREATED sessions
    - Prevents overwriting existing agent configurations
    - Idempotent: safe to restart server multiple times

[4] Agent configuration is customizable in auto_runner.py
    - Edit _register_default_agents() method
    - Restart server to apply changes
